# Lumen Automation Runner (Selenium + TestNG)

This directory is reserved for the automated testing runners and adapters.

In **Phase 5**, this module will contain:
- Selenium WebDriver + TestNG Java test runner harness
- Maven build configuration (`pom.xml`)
- Test listener hooks for capturing test statuses, execution timestamps, and failure stacktraces
- Extent Reports generator and artifact exporter
- Results parser that synchronizes execution metrics directly into Lumen
